# Changelog

## 0.2.0

- **Multiple bots**, each with its own persona, models, abilities, budget, channels, memory and knowledge base. Create from presets: group-chat companion, Q&A / support, study buddy or blank.
- **Persona & description**: name, avatar, color, description, greeting, personality, tone, emoji, reply length, language, backstory, rules or a fully custom prompt. The description syncs to Telegram and Discord.
- **Knowledge base** for Q&A bots: PDF, Word, Markdown, text, CSV, JSON, HTML or web pages, with an "only answer from the knowledge base" mode.
- **Channels from the dashboard**: Discord, Telegram, Slack and **QQ** (official QQ Bot API), with token checks and pause/resume.
- **Flatkey API key from the dashboard**, verified before saving; model picker loaded from your Flatkey catalog, plus custom model IDs.
- **Languages**: dashboard, website widget and built-in replies in English, Português, 日本語 and 中文.
- Default models: DeepSeek for chat and memory, GPT for images, Claude for web search.

## 0.1.0

- First release: one bot for Discord, Telegram, Slack and the web, with memory, web search, image reading and a cost-control dashboard.
