Abilities at a glance

Flatkey API key

Mochi runs on Flatkey. One key powers chat, image reading, web search and memory.

  1. Create a key on Flatkey

    Sign in or sign up, then create a new API key and copy it.

    Create a key on Flatkey ↗
  2. Paste it here and bind

    Mochi checks the key with Flatkey before saving. It's stored only on your server and is never shown in full again.

  3. Pick your models

    Once the key is bound, every model on your Flatkey account appears on the Models page.

Why Flatkey?

💸 Mainstream models like GPT, Claude, DeepSeek, Kimi and GLM are at least 20% below official pricing, and failed calls cost $0.

⏱️ A chatbot needs several kinds of models. With Flatkey that's one key, one balance and one bill instead of an account per provider.

Official models. Better prices.

Models

Every ability runs through your Flatkey key, so any model in the Flatkey catalog works for any job. Pick a strong model for chat and a small one for background memory.

Abilities & cost control

Turn abilities off to cut spend. Changes apply instantly, with no restart.

🧠 Memory

Remembers people (personality, facts, interests) and what each room talks about. Costs one cheap memory-model call every N messages per room.

🔎 Web search

Looks up facts it isn't sure about. Each search is one extra search-model call.

🖼️ Image reading

Reads images people send, using the vision model. Image input uses more tokens than text.
